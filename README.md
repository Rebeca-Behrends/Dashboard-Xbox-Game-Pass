# Xbox Game Pass — Dashboard de Vendas e Assinaturas

## Sobre o Projeto

Este projeto foi desenvolvido em Excel com o objetivo de transformar uma base de dados de assinantes do Xbox Game Pass em informações visuais para análise de vendas e comportamento das assinaturas.

O dashboard apresenta uma visão consolidada dos dados, permitindo analisar informações relacionadas aos planos contratados, valores das assinaturas, tipo de contratação, renovação automática e aquisição de conteúdos adicionais.

## Objetivo

O principal objetivo do projeto é utilizar recursos de **organização, tratamento, cálculos e visualização de dados no Excel** para criar um dashboard que facilite a interpretação dos resultados de assinaturas do Xbox Game Pass.

A proposta é transformar os dados da base em indicadores e visualizações que possibilitem uma análise mais rápida e objetiva do desempenho das assinaturas.


## Dados Utilizados

A base de dados contém informações referentes aos assinantes e suas respectivas assinaturas, contendo 295 registros de assinantes, organizados em uma tabela no Excel.


## Dashboard

O dashboard foi desenvolvido para apresentar uma visão visual dos principais dados relacionados às assinaturas do Xbox Game Pass.

Entre as análises realizadas estão:

* Valor das assinaturas;
* Distribuição dos planos;
* Renovação automática;
* Tipo de assinatura;
* Valores relacionados ao EA Play Season Pass;
* Valores relacionados ao Minecraft Season Pass;
* Comparações entre categorias de assinaturas.

Os dados foram organizados e utilizados em cálculos e tabelas dinâmicas para alimentar as análises apresentadas no dashboard.


## Ferramentas e Recursos Utilizados

O projeto foi desenvolvido utilizando o Microsoft Excel, com recursos como:

* Tabelas;
* Tabelas dinâmicas;
* Segmentações/filtros;
* Fórmulas e cálculos;
* `GETPIVOTDATA`;
* Gráficos;
* Organização e tratamento da base de dados;
* Dashboard para visualização dos indicadores.

## Estrutura da Planilha

O arquivo Excel está organizado em diferentes abas, cada uma com uma finalidade específica:

### `Assets`
Contém elementos visuais utilizados na construção do projeto, incluindo a **paleta de cores** utilizada no dashboard.

### `Bases`
Contém a base principal de dados dos assinantes e suas respectivas informações de assinatura.

### `Cálculos`
Contém tabelas dinâmicas e cálculos utilizados para gerar os indicadores e análises do dashboard.

### `Dashboard`
Apresenta a visualização final do projeto, reunindo as principais informações de forma organizada e visual.


## Como Reproduzir

Para visualizar o projeto:

Abra o arquivo no Microsoft Excel;
Acesse a aba **Dashboard** para visualizar a análise;
Consulte a aba **Bases** para visualizar os dados utilizados;
Acesse a aba **Cálculos** para verificar as tabelas dinâmicas e cálculos que dão suporte às análises.

Para reproduzir ou adaptar o projeto, é possível substituir ou atualizar os dados da aba Bases e atualizar as tabelas dinâmicas e demais elementos vinculados.
